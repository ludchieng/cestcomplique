# C’estCompliqué

Un test de couple à faire seul·e : 37 questions sur ce qui s’est vraiment passé, un bilan sans note, et « Les coulisses du bilan » pour voir quelle réponse fait apparaître chaque message.

Ce n’est pas un diagnostic, juste des pistes pour prendre un peu de recul. Les réponses restent dans le navigateur, rien n’est envoyé.

## Développer

```sh
pnpm install
pnpm dev
```

`pnpm build` produit le site dans `dist/`. Chaque push sur `main` le publie sur GitHub Pages.
